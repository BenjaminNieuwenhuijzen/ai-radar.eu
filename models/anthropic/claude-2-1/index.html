Claude 2.1

Retired · Language

Claude 2.1 is an update to Anthropic's Claude 2 language model, released in November 2023 through the API and as the model behind claude.ai. It raised the context window to 200K tokens and added system prompts and a beta tool-use feature; the model card appendix says it builds on Claude 2.0 rather than being a new base model.
