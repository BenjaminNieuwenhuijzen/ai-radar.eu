Claude 3.5 Haiku

Retired · Language, Multimodal

Claude 3.5 Haiku is a language model from Anthropic, presented as the next generation of its Haiku model at a speed similar to Claude 3 Haiku. It became available on the Claude API on 2024-11-04 as a text-only model, with image input added on 2025-02-24, and Anthropic also announced it for Amazon Bedrock and Google Cloud Vertex AI.
