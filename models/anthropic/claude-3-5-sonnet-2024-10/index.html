Claude 3.5 Sonnet (New)

Retired · Language, Multimodal

The October 2024 revision of Claude 3.5 Sonnet is an upgraded version of that Anthropic language model for text and image input, released under the same name but with its own API id, claude-3-5-sonnet-20241022. It introduced computer use as a public beta on the Anthropic API, Amazon Bedrock and Google Cloud Vertex AI, and Anthropic says it kept the price and speed of the June 2024 model.
