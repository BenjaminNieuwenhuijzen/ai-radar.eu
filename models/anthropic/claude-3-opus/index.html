Claude 3 Opus

Retired · Language, Multimodal · Milestone

Claude 3 Opus is a language model from Anthropic that accepts text and images and responds in text. It was introduced with Claude 3 Sonnet and Claude 3 Haiku as the Claude 3 family, which Anthropic ordered by capability with Opus above the other two, and was offered through the Claude API and on claude.ai for Claude Pro subscribers.
