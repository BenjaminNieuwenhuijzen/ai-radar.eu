Claude Instant 1.2

Retired · Language

Claude Instant 1.2 is an updated version of Claude Instant, which Anthropic positions as its quicker, lower-cost language model for tasks such as dialogue, text analysis, summarisation and document comprehension; it was released through the API in August 2023. Anthropic says it draws on strengths of Claude 2 and improves on Claude Instant 1.1 in maths, coding, reasoning and safety. [1] ● Primary source
