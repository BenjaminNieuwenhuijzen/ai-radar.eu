Claude Instant

Retired · Language · Milestone

Claude Instant is a language model that Anthropic introduced in March 2023 together with Claude, presenting it as the faster, lighter and lower-cost of the two versions. It was offered through Anthropic's API; this record covers the API versions claude-instant-1.0 and claude-instant-1.1. [1] [2]2024-09-04: Claude 1 and Instant models ● Primary source
