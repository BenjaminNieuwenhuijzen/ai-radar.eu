Claude Mythos Preview

Deprecated · Language, Reasoning

Claude Mythos Preview is a general-purpose model that Anthropic announced on 7 April 2026 with Project Glasswing, a defensive cybersecurity initiative. It was offered as an invitation-only research preview for Glasswing participants through the Claude API and major cloud platforms; Anthropic said it did not plan general availability and later called it the first Mythos-class model.
