Claude Opus 4.6

Available · Language, Multimodal, Reasoning

Claude Opus 4.6 is a language model in Anthropic's Claude Opus line, released on 5 February 2026 on claude.ai, the Claude API and major cloud platforms. It takes text and image input, launched with adaptive thinking and with context compaction in beta, and has a 1M token context window that was in beta at launch. [1] [2]Capabilities ● Primary source
