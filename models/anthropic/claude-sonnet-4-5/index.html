Claude Sonnet 4.5

Deprecated · Language, Multimodal, Reasoning

Claude Sonnet 4.5 is a language model in Anthropic's Sonnet line that accepts text and images, with a 200K-token context window and an extended thinking mode. It is offered in the Claude apps, on the Anthropic API, Amazon Bedrock and Google Cloud Vertex AI, and Anthropic presents it as a drop-in replacement for Claude Sonnet 4 at the same price.
