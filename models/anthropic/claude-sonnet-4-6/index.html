Claude Sonnet 4.6

Available · Language, Multimodal, Reasoning

Claude Sonnet 4.6 is a language model in Anthropic's Claude Sonnet line, released on 17 February 2026 on all Claude plans, Claude Code, the Claude API and major cloud platforms at the same price as Sonnet 4.5. It takes text and image input, supports adaptive and extended thinking, and became the default model for Free and Pro users on claude.ai. [1] [2]Capabilities ● Primary source
