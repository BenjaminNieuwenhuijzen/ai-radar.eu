Command A Vision

Available · Language, Multimodal

Command A Vision is a 112B-parameter model in Cohere's Command A family that reads images alongside text and answers in text, released on 31 July 2025 on the Cohere API with open weights for non-commercial research use. Cohere calls it its first commercial model that can interpret images and aims it at charts, diagrams, tables, document OCR and scene analysis. [1] [2] [3] ● Primary source
