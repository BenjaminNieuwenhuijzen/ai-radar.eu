DeepSeek-V3

Available · Language · Milestone

DeepSeek-V3 is a mixture-of-experts language model with 671B total and 37B activated parameters, offered in DeepSeek's web chat, through its API and as open weights together with the base model DeepSeek-V3-Base. DeepSeek pre-trained it on 14.8 trillion tokens and says it validated FP8 mixed-precision training at this scale for the first time. [1] [2]3. Model Downloads; 5.
