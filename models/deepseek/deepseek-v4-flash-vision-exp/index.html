DeepSeek-V4-Flash-Vision-Exp

Available · Language, Multimodal, Reasoning

DeepSeek-V4-Flash-Vision-Exp is an experimental model that DeepSeek calls its first multimodal model in the DeepSeek-V4 family, built on the V4-Flash architecture with added visual modules. It accepted text and images in the DeepSeek API from 2026-08-21, later got open weights under the MIT License and was retired in the API on 2026-09-10.
