Gemini 1.0 Pro

Retired · Language, Multimodal · Milestone

Gemini 1.0 Pro is the Gemini 1.0 size Google meant for a wide range of tasks. A tuned version ran in Bard from December 2023, and a week later it reached developers through the Gemini API and Vertex AI with a 32K-token context window, taking text only, with images through a separate Pro Vision endpoint. The Gemini API stopped supporting it in February 2025. [1] [2] [3] [4] ● Primary source
