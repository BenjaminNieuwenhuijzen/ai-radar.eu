Gemini 3 Flash

Preview · Language, Multimodal, Reasoning

Gemini 3 Flash is a multimodal language model in Google's Gemini Flash line, released in preview on 17 December 2025 through the Gemini API and Vertex AI and as the default model in the Gemini app. Google describes it as combining Gemini 3 Pro-level reasoning with the latency and cost of the Flash line. It was still a preview model on 1 October 2026. [1] [2] [3] ● Primary source
