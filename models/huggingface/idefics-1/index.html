IDEFICS

Available · Language, Multimodal · Milestone

IDEFICS is an open-weights visual language model from Hugging Face that takes interleaved images and text and produces text, released in 9B and 80B sizes, each as a base and an instruction-tuned version. Hugging Face presents it as an open reproduction of DeepMind's Flamingo, built from public data and frozen LLaMA v1 and OpenCLIP backbones. [1] [2]Model Details ● Primary source
