SmolLM2

Available · Language · Milestone

SmolLM2 is the second generation of Hugging Face's compact open-weight language models, released in 135M, 360M and 1.7B sizes under Apache 2.0. Hugging Face describes them as light enough to run on-device; the 1.7B model was trained on about 11 trillion tokens, with new math, code and instruction datasets built for the line.
