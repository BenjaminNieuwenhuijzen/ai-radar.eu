SmolVLA

Available · Language, Multimodal, Robotics · Milestone

SmolVLA is a 450M-parameter open-weight vision-language-action model for robotics from Hugging Face's LeRobot project. It pairs SmolVLM2 with an action expert trained with flow matching to turn camera images, robot state and an optional instruction into continuous actions; Hugging Face says it can run on a CPU and pretrained it on community-shared LeRobot datasets.
