Llama 3.2

Available · Language, Multimodal

Llama 3.2 is a set of open-weight Meta models released on 25 September 2024: text-only 1B and 3B models aimed at on-device use, and 11B and 90B Vision models, which Meta describes as the first Llama models to support vision tasks. The small models were distilled from Llama 3.1, and the Vision models add an image adapter to Llama 3.1 text models. [1] [2] [3] [4] ● Primary source
