Llama 3.3

Available · Language

Llama 3.3 is a text-only multilingual 70B model from Meta, released on 6 December 2024 as open weights under the custom Llama 3.3 Community License, in an instruction-tuned version only. Meta says it improves on Llama 3.1 70B; in April 2025 Meta added a Llama 3.3 8B model for fine-tuning in its Llama API preview. [1] [2] [3] [4]Introducing Llama API in preview ● Primary source
