Muse Spark 1.1

Available · Language, Multimodal, Reasoning

Muse Spark 1.1 is a multimodal reasoning model in Meta's Muse series that Meta says is built for agentic tasks. It succeeded the first Muse Spark in Meta AI and launched with the public preview of the Meta Model API, which lists it as muse-spark-1.1 with text, image, video, audio and PDF input and a 1,048,576-token context window.
