Muse Spark 1.3

Available · Language, Multimodal, Reasoning

Muse Spark 1.3 is a multimodal reasoning model in Meta's Muse series, offered in the Meta Model API and the Muse Code terminal agent. Meta says it improves agentic and coding work and is easier to use; it adds a max reasoning effort level on the Standard tier, and the API docs say its audio understanding is not fully supported.
