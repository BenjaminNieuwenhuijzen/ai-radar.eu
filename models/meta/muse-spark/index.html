Muse Spark

Status unknown · Language, Multimodal, Reasoning · Milestone

Muse Spark is the first model in Meta's Muse series, built by Meta Superintelligence Labs. Meta describes it as a natively multimodal reasoning model with tool use; it launched in the Meta AI app and on meta.ai with Instant and Thinking modes, and select partners got a private API preview.
