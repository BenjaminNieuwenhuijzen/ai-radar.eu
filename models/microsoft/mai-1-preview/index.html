MAI-1-preview

Status unknown · Language · Milestone

MAI-1-preview is a mixture-of-experts language model that Microsoft AI calls its first foundation model trained end to end in-house, announced on 28 August 2025. It was offered for public testing on LMArena and to trusted testers through an API, and Microsoft AI positions it for following instructions and answering everyday consumer queries.
