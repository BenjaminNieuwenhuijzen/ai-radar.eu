MAI-Code-1.1-Flash

Available · Language, Multimodal, Code

MAI-Code-1.1-Flash is a coding model from Microsoft AI, released on 11 August 2026 as the successor to MAI-Code-1-Flash and offered inside GitHub Copilot. It is a sparse mixture-of-experts model with 5 billion active and 138 billion total parameters that adds image input, and Microsoft says it uses fewer tokens per task at a quarter of the price.
