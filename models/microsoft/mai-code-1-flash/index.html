MAI-Code-1-Flash

Retired · Language, Code

MAI-Code-1-Flash is a coding model from Microsoft AI, released on 2 June 2026 and offered only inside GitHub Copilot, where GitHub deprecated it across all Copilot experiences on 10 September 2026. A sparse mixture-of-experts model with 5 billion active and 137 billion total parameters, it was trained from a MAI-Thinking-1 checkpoint and with the GitHub Copilot production harness.
