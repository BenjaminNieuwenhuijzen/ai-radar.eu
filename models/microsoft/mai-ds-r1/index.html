MAI-DS-R1

Available · Language, Reasoning

MAI-DS-R1 is an open-weights reasoning model released by Microsoft on 17 April 2025: a version of DeepSeek-R1 that the Microsoft AI team post-trained to answer topics the original blocked and to improve its risk profile. The weights are on Hugging Face under the MIT licence; the hosted API on Azure AI Foundry was retired on 27 February 2026. [1] [2] [3]Microsoft table: MAI-DS-R1 ● Primary source
