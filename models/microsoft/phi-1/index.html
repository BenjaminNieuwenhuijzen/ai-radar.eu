Phi-1

Available · Language, Code · Milestone

Phi-1 is a 1.3 billion parameter Transformer language model from Microsoft, specialised for basic Python coding and introduced in the paper Textbooks Are All You Need in June 2023. It was trained on textbook-quality web data plus synthetic textbooks and exercises generated with GPT-3.5, and its weights are published on Hugging Face under the MIT License.
