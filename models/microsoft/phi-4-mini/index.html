Phi-4-mini

Available · Language

Phi-4-mini is a 3.8-billion-parameter text model in Microsoft's Phi family of small language models, released on 26 February 2025 with Phi-4-multimodal. It was offered in Azure AI Foundry, the NVIDIA API Catalog and as MIT-licensed open weights on Hugging Face, and supports function calling, 23 languages and a 128K-token context.
