Codestral Mamba

Available · Language, Code

Codestral Mamba is a 7B code model from Mistral AI based on the Mamba architecture rather than a Transformer, which Mistral says gives linear-time inference. It was released under Apache 2.0 with weights on Hugging Face and offered for testing on la Plateforme; Mistral says it tested in-context retrieval up to 256k tokens. [1] [2] [3] ● Primary source
