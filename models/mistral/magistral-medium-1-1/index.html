Magistral Medium 1.1

Retired · Language, Reasoning

Magistral Medium 1.1 is a reasoning model in Mistral AI's Magistral line, released on 24 July 2025 together with Magistral Small 1.1 and offered as API model magistral-medium-2507. The docs list text input, text output and a 40k context window. [1]July 24, 2025 [2] ● Primary source
