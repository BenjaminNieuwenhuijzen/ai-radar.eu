Magistral Small 1.2

Available · Language, Multimodal, Reasoning

Magistral Small 1.2 is a 24B-parameter reasoning model from Mistral AI, built on Mistral Small 3.2 and released on 17 September 2025 on Mistral's API and as Apache 2.0 open weights. It accepts text and images; Mistral says a quantized version fits on a single RTX 4090 or a 32GB MacBook, and the weights stayed available after the API retirement in July 2026.
