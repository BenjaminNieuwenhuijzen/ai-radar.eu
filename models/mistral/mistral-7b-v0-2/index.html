Mistral 7B v0.2

Available · Language

Mistral 7B v0.2 is an update to Mistral AI's open 7B language model, first offered on 11 December 2023 as Mistral 7B Instruct v0.2 behind the mistral-tiny API endpoint of la Plateforme, later renamed open-mistral-7b. The instruct weights are on Hugging Face under Apache 2.0, and the model has a 32k-token context window. [1]Generative endpoints, Mistral-tiny [2]February 26, 2024 [3] [4] ● Primary source
