Mistral 7B v0.3

Available · Language

Mistral 7B v0.3 is a minor update to Mistral AI's open 7B language model, released on 22 May 2024 as base and instruct checkpoints with open weights on Hugging Face under Apache 2.0 and served on Mistral's API as open-mistral-7b. It extends the vocabulary to 32768 tokens, and the instruct version adds function calling. [1] [2] [3] ● Primary source
