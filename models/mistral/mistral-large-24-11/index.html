Mistral Large 24.11

Available · Language

Mistral Large 24.11 is an update of Mistral AI's Mistral Large 2 language model, a 123B dense model released alongside Pixtral Large; the changelog calls it Mistral Large 2.1. Mistral describes better long-context understanding, a new system prompt and more accurate function calling, and offered it on the API as mistral-large-2411 and as weights under the Mistral Research License.
