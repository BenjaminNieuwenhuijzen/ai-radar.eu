Mistral Medium 3.5

Available · Language, Multimodal, Reasoning

Mistral Medium 3.5 is a dense 128B-parameter Mistral AI model that handles instruction following, reasoning and coding in one set of weights, with text and image input and a 256k-token context window. It was released on 28 April 2026 as open weights under a Modified MIT licence and on the API, and in May 2026 became the default model in Le Chat and Mistral Vibe, in public preview.
