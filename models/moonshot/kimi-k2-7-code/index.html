Kimi K2.7 Code

Available · Code, Agentic

Kimi K2.7 Code is an open-weight coding model released on 2026-06-12, a coding-specialised version of Kimi K2.6 with 1 trillion total and 32 billion activated parameters and a 256K context window. It is offered through the Kimi API and the Kimi Code CLI; Moonshot AI reports fewer reasoning tokens than K2.6. [1] [2] [3] ● Primary source
