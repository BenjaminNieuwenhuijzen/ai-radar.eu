Kimi K3.1 Pro

Available · Multimodal, Agentic, Code, Reasoning

Kimi K3.1 Pro is a post-trained version of Kimi K3, released on 2026-10-23 in Kimi.ai, Kimi Work, Kimi Code and the Kimi API together with a faster Highspeed variant. It keeps the 1M-token context window; Moonshot AI says it removed cyber-related training data and promised full weights by 2026-11-04. [1] [2] [3] ● Primary source
