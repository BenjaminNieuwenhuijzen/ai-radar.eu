Llama-3.1-Nemotron-51B-Instruct

Available · Language

Llama-3.1-Nemotron-51B-Instruct is a 51-billion-parameter chat model from NVIDIA, released on 23 September 2024 and derived from Meta's Llama-3.1-70B through block-wise distillation and neural architecture search. It was offered as an NVIDIA NIM through an API and as open weights on Hugging Face; NVIDIA says it fits on a single H100 GPU. [1] [2] ● Primary source
