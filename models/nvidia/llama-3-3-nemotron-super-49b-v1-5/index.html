Llama-3.3-Nemotron-Super-49B-v1.5

Available · Language, Reasoning

Llama-3.3-Nemotron-Super-49B-v1.5 is an open-weights NVIDIA reasoning language model of about 49 billion parameters, derived from Meta's Llama-3.3-70B-Instruct and released on Hugging Face and as a preview API on build.nvidia.com. NVIDIA calls it a significantly upgraded version of Super v1, post-trained for reasoning, chat and agentic tasks; reasoning is on by default and can be switched off. [1] [2] ● Primary source
