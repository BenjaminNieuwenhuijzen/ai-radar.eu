Nemotron 3.5 Lightning

Available · Language, Reasoning

Nemotron 3.5 Lightning is an open-weights reasoning language model with 30B total and 3B active parameters that NVIDIA added to the Nemotron 3 family after Nemotron 3 Nano. NVIDIA aims it at high-volume agent work such as tool calls and subagent delegation, and released it with the NeMo Switchyard routing library, as a download and on build.nvidia.com.
