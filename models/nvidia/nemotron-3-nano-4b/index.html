Nemotron 3 Nano 4B

Available · Language, Reasoning

Nemotron 3 Nano 4B is a small open-weights text model in NVIDIA's Nemotron 3 family that handles reasoning and non-reasoning tasks. NVIDIA calls it its first model optimised for on-device use and built it by pruning and distilling Nemotron Nano 9B v2 into a hybrid of mostly Mamba-2 layers with about 4B parameters.
