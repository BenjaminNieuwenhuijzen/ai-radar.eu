Nemotron 3 Nano Omni

Available · Language, Multimodal, Reasoning

Nemotron 3 Nano Omni is an open-weights multimodal reasoning model in NVIDIA's Nemotron 3 family that takes video, audio, images and text and produces text. It pairs the Nemotron 3 Nano 30B-A3B language model with vision and speech encoders; NVIDIA positions it as the perception sub-agent in agent systems and offered it as a download, on build.nvidia.com and via partners.
