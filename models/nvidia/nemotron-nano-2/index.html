Nemotron Nano 2

Available · Language, Reasoning · Milestone

Nemotron Nano 2 is a family of open-weights hybrid Mamba-Transformer reasoning models that NVIDIA released on Hugging Face with 9B and 12B checkpoints and a 128K-token context. The 9B reasoning model, compressed from the 12B base so that 128K-token inference fits on one A10G GPU, was also on the NVIDIA API Catalog; users can switch reasoning off and cap thinking tokens.
