GPT-3.5 Turbo

Deprecated · Language

GPT-3.5 Turbo is an OpenAI language model released in the API on 1 March 2023 as gpt-3.5-turbo, which OpenAI said was the model used in the ChatGPT product, and first marketed as the ChatGPT API. It came with a chat endpoint that takes a list of messages and was priced at one tenth of OpenAI's existing GPT-3.5 models. [1] ● Primary source
