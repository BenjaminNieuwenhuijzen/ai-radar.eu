GPT-3.5

Retired · Language

GPT-3.5 is OpenAI's name for a series of API models trained on a blend of text and code from before the fourth quarter of 2021: the code completion base model code-davinci-002 and the instruction-tuned text-davinci-002 and text-davinci-003. The first two arrived in March 2022 as new versions of Codex and GPT-3; all three were shut down in January 2024. [1] [2] [3] ● Primary source
