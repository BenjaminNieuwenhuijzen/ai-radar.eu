GPT-3

Retired · Language · Milestone

GPT-3 is an autoregressive language model from OpenAI with 175 billion parameters, introduced in May 2020 in a paper that applies it to tasks given as text instructions or a few examples in the prompt. OpenAI offered it only through its commercial API, launched in private beta in June 2020, and shut down the base GPT-3 API models in January 2024. [1] [2] [3] [4] ● Primary source
