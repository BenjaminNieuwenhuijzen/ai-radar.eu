GPT-4

Deprecated · Language, Multimodal · Milestone

GPT-4 is an OpenAI model that OpenAI describes as a large multimodal model taking image and text input and producing text. It was released on 14 March 2023 in ChatGPT Plus and through an API waitlist, with image input following later, and its technical report withholds details on architecture, model size, training compute and data.
