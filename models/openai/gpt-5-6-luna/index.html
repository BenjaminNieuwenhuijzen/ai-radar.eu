GPT-5.6 Luna

Available · Language, Multimodal, Reasoning

GPT-5.6 Luna is the smallest tier of OpenAI's GPT-5.6 family, a reasoning language model for text and image input that the API docs describe as meant for cost-sensitive, high-volume work. Released on 9 July 2026 in the API, ChatGPT, Codex and Amazon Bedrock, it became the default ChatGPT model for Free and Go users in August 2026. [1] [2] [3] [4] [5] ● Primary source
