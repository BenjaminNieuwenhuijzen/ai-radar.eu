GPT-5

Deprecated · Language, Multimodal, Reasoning · Milestone

GPT-5 is a language and reasoning model in OpenAI's GPT line for text and image input, released on 7 August 2025 in ChatGPT and the API. In ChatGPT it is a system of a fast model, a reasoning model (GPT-5 thinking) and a router, and became the default for signed-in users; in the API it came in three sizes, gpt-5, gpt-5-mini and gpt-5-nano.
