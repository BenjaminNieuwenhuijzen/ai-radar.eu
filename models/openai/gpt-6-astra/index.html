GPT-6 Astra

Available · Language, Multimodal, Reasoning · Milestone

GPT-6 Astra is the first model of OpenAI's GPT-6 generation, a reasoning language model for text and image input released on 3 September 2026 in ChatGPT Work, Codex, the API and Amazon Bedrock, after a first rollout to a limited set of organizations. OpenAI says it is its first model to reach the Critical level of cybersecurity capability under its Preparedness Framework. [1] [2] [3] [4] [5] ● Primary source
