InstructGPT

Retired · Language

InstructGPT is a set of GPT-3 language models that OpenAI fine-tuned with human feedback to follow user instructions, offered through the OpenAI API, where they became the default language models in January 2022. The research models come in 1.3B, 6B and 175B sizes; OpenAI says the API versions used a slightly different fine-tuning procedure. [1] [2] ● Primary source
