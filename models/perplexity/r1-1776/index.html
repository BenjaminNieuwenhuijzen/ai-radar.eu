R1 1776

Retired · Language, Reasoning

R1 1776 is a version of DeepSeek-R1 that Perplexity post-trained to remove Chinese Communist Party censorship, published as open weights under the MIT licence on 18 February 2025 and offered in the Sonar API as an offline chat model without search. Perplexity removed it from the API on 1 August 2025; a Llama 70B distilled version was also published. [1] [2] [3] [4] [5] ● Primary source
