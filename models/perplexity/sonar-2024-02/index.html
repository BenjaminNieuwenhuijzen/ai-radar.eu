Sonar (February 2024)

Retired · Language · Milestone

Sonar (February 2024) refers to Perplexity's sonar-small and sonar-medium language models, launched on 23 February 2024 on the Perplexity API, each as a chat id and a search-enhanced online id. The API docs listed them at 7B and 8x7B parameters without naming base models. All four ids were removed on 14 May 2024. [1] [2] [3] ● Primary source
