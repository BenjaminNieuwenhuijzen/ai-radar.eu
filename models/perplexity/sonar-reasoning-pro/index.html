Sonar Reasoning Pro

Deprecated · Language, Reasoning

Sonar Reasoning Pro is a reasoning model in Perplexity's Sonar API, first listed in the API docs in early February 2025, that returns its chain of thought in the response. Perplexity's docs say it is powered by DeepSeek R1 and aimed at complex, multi-step topics; Perplexity recommended it in place of R1 1776 and Sonar Reasoning when those left the API.
