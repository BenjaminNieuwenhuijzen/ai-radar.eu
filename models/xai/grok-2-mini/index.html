Grok-2 mini

Status unknown · Language

Grok-2 mini is a smaller language model that xAI released alongside Grok-2 on 13 August 2024, describing it as a sibling of Grok-2 that balances speed and answer quality. It launched in beta on X for Premium and Premium+ subscribers, with access through an enterprise API announced for later that month. [1] ● Primary source
