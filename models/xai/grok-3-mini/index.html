Grok 3 mini

Status unknown · Language, Reasoning

Grok 3 mini is a smaller xAI language model, unveiled alongside Grok 3 on 19 February 2025 with a beta reasoning model, Grok 3 mini (Think). xAI presented it as cost-efficient reasoning for STEM tasks that need less world knowledge; the Grok 3 models became generally available on the xAI API on 3 April 2025.
