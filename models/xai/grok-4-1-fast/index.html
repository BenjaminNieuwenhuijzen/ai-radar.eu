Grok 4.1 Fast

Retired · Language, Reasoning

Grok 4.1 Fast is an xAI tool-calling model released on the xAI API on 19 November 2025 together with the Agent Tools API, as reasoning and non-reasoning model ids with a 2-million-token context window. xAI positions it for production agents in areas such as customer support and finance; it was retired from the API on 15 May 2026.
