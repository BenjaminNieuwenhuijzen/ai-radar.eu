Grok 4.20

Available · Language, Multimodal, Reasoning

Grok 4.20 is a language model in xAI's Grok line that takes text and images and returns text, first released as a beta in the Grok apps in February 2026 and on the xAI API in March 2026 as separate reasoning and non-reasoning models. xAI says it can run as a single agent or as several cooperating agents, offered as Grok 4.20 Multi-Agent.
