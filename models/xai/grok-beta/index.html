grok-beta

Status unknown · Language, Multimodal

grok-beta is a preview language model that xAI offered on its API from the start of the API public beta on 4 November 2024, as the provisional name of a new Grok model in the final stages of development. xAI gave it a 128,000-token context window and function calling; a multimodal version with image input, grok-vision-beta, followed as a preview.
