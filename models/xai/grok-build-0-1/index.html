Grok Build 0.1

Available · Language, Multimodal, Reasoning, Code

Grok Build 0.1 is an xAI coding model trained for agentic coding, including web development, debugging and MCP support, and the model behind xAI's Grok Build coding agent. It takes text and images and returns text; after early access in May 2026 it opened on the xAI API as a public beta on 29 May 2026.
