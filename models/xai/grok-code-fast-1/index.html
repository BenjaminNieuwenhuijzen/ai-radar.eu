Grok Code Fast 1

Retired · Language, Code, Reasoning

Grok Code Fast 1 is an xAI reasoning model for agentic coding, released on 28 August 2025 on the xAI API and, free for a limited time, through coding tools such as GitHub Copilot and Cursor. xAI says it built the model from scratch on a new architecture and trained it on programming content and real-world pull requests. It was retired from the API on 15 May 2026. [1] [2] [3] ● Primary source
